# 《龙与奇幻城》完整卡牌图鉴与设计思路

当前版本共 46 张原创小丑牌。稀有度并不只是价格标签：**传奇牌建立长期引擎，稀有牌改变一局的路线，罕见牌提供可组合的战术零件。**

## 传奇（4 张）

| # | 卡牌 | 实际效果 | 玩法与设计思路 |
|---:|---|---|---|
| 1 | 红龙史矛革 | 每累计主动花费 $7，永久获得 X0.20 倍率。 | 把“花钱”从资源损耗改写成长投资。金币、火焰与贪欲是史矛革最直接的视觉语言；玩家越敢消费，它越像真正盘踞金山的龙。 |
| 2 | 黑毒龙阿萨比斯 | 每累计摧毁 3 张扑克牌，所有打出的牌永久额外触发 1 次。 | 毁牌流的终极发动机。黑紫毒雾、残牌与龙爪共同表达“腐蚀—分解—再利用”，代价越重，后续每张牌的回报越恐怖。 |
| 3 | 骷髅龙骨恩 | 每次出牌结算后，向当前手牌加入一张随机花色的红蜡封钢铁 K。 | 它同时制造钢铁牌、红蜡封、K 与“新增牌”事件，因此天然能接入多条体系。画面用骨龙、蜡封与冷色雷光表现死亡材料被重新锻造成武器。 |
| 4 | 中华龙 | 其他非普通小丑产生有效触发时，永久获得 +1 倍率。 | 奖励“让一整座小丑牌城运转”，而不是只堆一张主 C。龙珠与盘旋姿态象征聚拢百家力量，成长速度则由触发密度决定。 |

## 组合提示

- **毁灭引擎**：黑毒龙阿萨比斯 + 牛魔王 / 大白鲨 / 矮人矿工 / 姜戈。
- **新增牌引擎**：骷髅龙骨恩 + 发条橙；新增的钢铁红蜡封 K 会直接进入当前手牌并触发标准新增牌流程。
- **重触发引擎**：疯狂树魔 + 蜘蛛女巫 + 斑纹巨蟒；注意消耗牌槽位。
- **经济引擎**：红龙史矛革 + 海盗船长库克 / 基金经理伊森 / 黑客 / 银翼杀手。
- **少牌出手**：橡皮头 + 丑巨人刚比 + 姜戈，利用未出牌与少量计分牌创造价值。
